Getting started

Welcome to EVEVPS

Windows RDP and Linux VPS servers in New York with NVMe SSD storage, DDoS protection and automatic setup in about a minute.

EVEVPS sells Windows VPS servers, which you use over the Remote Desktop Protocol (RDP), and Linux VPS servers, all hosted in our New York datacenter. Choose a plan and an operating system, pay with crypto, and the server sets itself up on its own. Your login details are usually emailed to you within 1 minute of payment.

Every plan includes NVMe SSD storage, DDoS protection, a dedicated IPv4 address, unlimited OS reinstalls, a dedicated control panel, and full Administrator or root access. You manage everything from the client area.

Linux VPS

KVM Linux servers with root access. Ubuntu, Debian, AlmaLinux, Rocky Linux and more.

Deploy a server

  1. Pick a product. Open the store and choose Windows RDP or Linux VPS.
  2. Choose a plan and OS. Select the plan size and the operating system you want installed.
  3. Pay with crypto. Check out and pay the invoice. Setup starts as soon as payment confirms.
  4. Connect. Your IP address and login details arrive by email, usually within 1 minute. Connect over RDP (Windows) or SSH (Linux).
